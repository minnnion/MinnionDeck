Make it full screen

Hide the browser bars so this feels like an app.

For a home screen icon: browser menu, then Add to Home screen.

Safari on iPhone can't hide its bars for a web page. To use it like an app:

  1. Tap the Share button.
  2. Choose Add to Home Screen.
  3. Open Minniondeck from your Home Screen and type the code from your PC.

Stop the certificate warning

Your PC makes its own certificate for this page. Install it on this phone once and the warning is gone, also from the Home Screen. It only works for addresses on your home network, so it can't vouch for any other website.

Download the certificate
  1. Tap Download above, then Allow.
  2. Open Settings, tap Profile Downloaded, then Install.
  3. Open Settings › General › About › Certificate Trust Settings and turn on MinnionDeck on this PC.
  4. Close this page and open it again.
